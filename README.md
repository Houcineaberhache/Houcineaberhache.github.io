# Houcine Aberhache — Portfolio

## Run locally
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click it and choose **Open with Live Server** (or simply open the HTML file in your browser).

## Publish on GitHub Pages
Create a repository named `Houcineaberhache.github.io`, upload these files, then enable GitHub Pages from repository Settings → Pages.

## Main files
- `index.html` — website content
- `css/style.css` — design
- `js/script.js` — small interactions
- `assets/` — add project screenshots here later
